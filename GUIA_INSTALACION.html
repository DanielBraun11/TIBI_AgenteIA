El cerebro del agente. Aquí vive TIBI y sus dos sub-agentes especializados, definidos con Google ADK.

Antes de instalar

Requisitos

Obligatorio

Python 3.10+

Si no lo tienes, descárgalo en python.org/downloads y marca «Add Python to PATH» durante la instalación.

Obligatorio

Red corporativa / VPN

El agente llama al proxy LiteLLM interno de MasOrange. Sin acceso a la red corporativa no podrá conectarse al modelo.

Obligatorio

Token personal

Un token propio del proxy LiteLLM (formato sk-…). Consíguelo en Gemini Enterprise hablando con el agente CloudAI.

Recomendado

Chrome o Edge

Necesario para la función de dictado por voz (Web Speech API). En otros navegadores el chat de texto sigue funcionando.

Instalación

Pasos de instalación

1

Descomprime el ZIP

Extrae TIBI_tv_agent.zip en la carpeta que quieras (por ejemplo C:\TIBI\). Obtendrás una carpeta tv_agent/ con todo el proyecto.

2

Ejecuta el instalador

Entra en tv_agent/ y haz doble clic en instalar.bat. Se abrirá una ventana de terminal.

3

Introduce tu token

El instalador te pedirá tu token personal del proxy corporativo (sk-…). Lo guardará en un fichero .env local que no se comparte con nadie.

4

Espera a que termine

El instalador crea el entorno virtual Python (.venv/) e instala todas las dependencias automáticamente. Puede tardar 2–3 minutos la primera vez.

5

Inicia el agente

Haz doble clic en iniciar.vbs para la demo — arranca el servidor y abre el navegador en http://localhost:8000 automáticamente. Si prefieres ver los logs, usa iniciar.bat.

Problemas frecuentes

Solución de problemas

python no reconocido al abrir el .bat Reinstala Python marcando «Add to PATH»
Error de conexión al modelo de IA Activa la VPN o conéctate a la red corporativa
Token inválido o expirado Pide uno nuevo al agente CloudAI en Gemini Enterprise y edita el .env
Puerto 8000 ya en uso Cierra otras aplicaciones en ese puerto o reinicia
Clientes no encontrados en CSV Verifica que la carpeta ficheros/ contiene los dos CSV
El micrófono no funciona Usa Chrome o Edge; Web Speech API no está disponible en Firefox
